# 과제 2 스토리 -> 이미지 생성 -> 영상 생성하기


스토리      : Q&A IBS 성경 묵상의 유익을 알리고 싶어요.
                 성경이 3500년 전에, 2000년 전에 쓰여잖아
                 그런데 나는 오늘 여기서 성경을 묵상하려고 하잖아 
	     그래서 성경이 어려워 모르는 단어도 많고 처음 들어본 지명, 사람들의 이름
                 무엇보다 문학적인 표현도 많이 달라 그 글이 쓰여진 곳에서는 지금도 오른쪽에서 왼쪽으로
                 글을 읽어.
	     그런데 묵상하려는 사람들은 이걸 모르기 때문에 성경이 어렵게만 느껴지거든

                  성경이 어렵지만 하나님은 오늘도 성경을 통해 자신을 계시하시고 우리와 말씀을 통해 
                  교제하고 싶어하시지
                  어린 아이도 성경을 묵상하고 싶어 하도록 광고를 하고 싶어
                  
                  Q&A IBS방식으로 성경을 묵상할 때
	      성경은 오늘 내게 말씀하시는 하나님을 만날 수 있게 하거든

                   오늘 내가 성경을 통해 말씀하시는 하나님과 함께 걷는 것은
                   어둠속에 빛을 비추시는 하나님과 함께 환하고 밝은 하루를 걷는 것이지
                  

브렌드 아이덴티티 : A Light In The Darkness

캠페인 목표/핵심 메시지 : Q&A IBS!  빛되신 주님과 만나요

씬 구성 : 모두 4씬으로 구성

사용 도구 목록 : 
1단계 
이미지를 GPT로 생성항 것을 Gemini에서 동영상 생성했을 때 
주인공에게 촛점을 맞추게 되었을 때, 광고의 목적을 담고 있는 배경의 활자들이 보이지 않게 되어
영상을 생성하는 프롬프트를 여러번 수정하였어도 만족한 결과를 얻을 수 없었다.  

2단계
동일 주제의  영상 만들기를 학습한 Gemini에게 2D 이미지 생성 부터 하여 1단계에서 발생한 시간, 비용, 동영상 생성 불만족을 해결 할 수 있었다.

2D 이미지 생성 : Gemini
영상제작 : Gemini flash
편집 프로그램 Canva에서 영상을 편집하고, 
배경 음악을 Suno에서 
한국어 대사(내레이션)를  네이버 클로버 더빙에서하여  
한 편의 완성도 높은 에니메이션 영상을 생성했다.



🎬 성경을 이해하는 열쇠, IBS 애니메이션 스토리보드
[Scene 1] 시공간의 간격
씬 번호 / 씬 길이: #1 / 8초
목표 메시지: 성경은 배경지식과 언어의 장벽 때문에 아이들이 스스로 읽기에 어렵다.
화면 구성: * 구도: 아이를 중심으로 좌우에 두루마리가 배치된 대칭형 전경 바스트 샷 ➡️ 매우 느린 줌인(Parallax 효과 적용).
피사체/배경: 책상에 앉아 성경을 보며 고개를 갸우뚱하고 볼을 긁는 소년. 배경에는 고대 문자들과 세계지도가 부유함.
텍스트: 상단 왼쪽에 "시공간의 간격", 소년 머리 위에 말풍선 자막 있음.
내레이션 (화면 카피): "성경은 3500년 전 이야기라 그런지… 모르는 단어와 지명이 너무 많아서 읽기가 너무 어려워요…"
사용 도구와 목적: * 비디오 (Gemini Veo): 정적인 2D 일러스트에 눈 깜빡임과 부유 효과를 주어 아이의 고민에 몰입하게 만듦.
오디오 (Suno / TTS): 잔잔하고 조금은 쓸쓸한 느낌의 어쿠스틱 기타 음악 시작 ➡️ 시무룩한 아이 목소리(TTS).
입력 프롬프트 + 출력 결과: * Create a gentle cinematic animation from this 2D illustration. The child studies the Bible but looks increasingly puzzled...
➡️ 성경을 보며 고민하는 소년과 부드럽게 움직이는 고대 활자 영상 출력.
파일명/링크: video_scene_01_puzzled_boy.mp4
[Scene 2] 하나님의 마음
씬 번호 / 씬 길이: #2 / 8초
목표 메시지: 성경은 어렵지만, 하나님은 말씀을 통해 우리와 소통하기를 원하신다.
화면 구성:
구도: 우측 상단에서 거대한 손이 내려오는 와이드 하이앵글 샷. 하단에 작은 세 가지 일상 컷 배치.
피사체/배경: 하늘 구름 사이로 내려오는 하나님의 손, 중앙에서 성경을 읽는 아이들, 하단의 예수님과 함께하는 아이들 그림.
텍스트: 상단 왼쪽에 "하나님의 마음", 우측에 "나와 교제하자..." 말풍선 자막 있음.
내레이션 (화면 카피): "하지만 하나님은 성경 말씀을 통해 우리와 깊은 교제를 나누고 싶어 하세요."
사용 도구와 목적:
비디오 (Gemini Veo): 내미는 손에 따뜻한 광원 효과를 주고 인물들이 서로 대화하는 모션을 주어 따뜻함 강조.
오디오 (Suno / TTS): 배경 음악이 조금 더 따뜻하고 포근한 톤으로 전환 ➡️ 자상한 해설자 톤의 내레이션 오디오.
입력 프롬프트 + 출력 결과:
Animate this 2D illustration... The large hand reaching from the top right softly glows with a warm, brilliant light. The figures move gently...
➡️ 신비롭게 빛나는 손과 소통하는 인물들의 따뜻한 영상 출력.
파일명/링크: video_scene_02_gods_heart.mp4
[Scene 3] IBS 다리의 발견
씬 번호 / 씬 길이: #3 / 8초
목표 메시지: 어려워진 성경을 이어주는 해결책으로 'IBS'라는 다리를 발견한다.
화면 구성:
구도: 절벽과 절벽 사이를 연결하는 'IBS' 다리를 보여주는 풀 샷 ➡️ 미세한 돌리 인.
피사체/배경: 왼쪽 절벽의 소녀(책 소유), 오른쪽 절벽의 소년(스마트폰 소유). 다리 위를 장식하는 돋보기, 두루마리 아이콘들.
텍스트: 다리 중앙에 크게 "I", "B", "S" 알파벳 위치.
내레이션 (화면 카피): "아! 'IBS'라는 다리가 있었구나! 이걸 통하면 성경을 제대로 이해할 수 있겠어!"
사용 도구와 목적:
비디오 (Gemini Veo): 정적인 타이포그래피에 부드러운 순차 반짝임 효과를 주어 해결책의 등장을 극적으로 연출.
오디오 (Suno / TTS): 음악에 맑은 실로폰 소리(Celesta)가 더해지며 반전 ➡️ 깨달음을 얻고 기뻐하는 밝은 아이 목소리(TTS).
입력 프롬프트 + 출력 결과:
Animate this 2D illustration... On the center bridge, the large letters 'I', 'B', and 'S' softly and sequentially flash with a warm, brilliant golden light...
➡️ IBS 글자가 순서대로 반짝이며 신비로운 분위기를 내는 다리 영상 출력.
파일명/링크: video_scene_03_ibs_bridge.mp4
[Scene 4] 말씀에 몰입한 소년
씬 번호 / 씬 길이: #4 / 8초
목표 메시지: IBS를 통해 성경을 읽으며 하나님의 마음을 깨닫고 큰 기쁨을 누린다.
화면 구성:
구도: 성경 책과 아이의 미소를 클로즈업하는 따뜻한 로우앵글 시네마틱 줌인 샷.
피사체/배경: 책상에서 환하게 웃으며 성경을 읽고 있는 소년. 주변에 예수님과 성경 인물 아이콘들이 은은하게 빛남.
텍스트: 자막 텍스트 없음 (오직 소년의 표정과 빛에 집중).
내레이션 (화면 카피): "우와! 성경이 이렇게 쉽고 재밌는 책이었다니! 이제 하나님의 마음이 조금씩 느껴져요!"
사용 도구와 목적:
비디오 (Gemini Veo): 성경 책 자체에서 황금빛 조명이 은은하게 뿜어져 나오게 하여 소년의 얼굴을 밝히고 감동을 시각화.
오디오 (Suno / TTS): 음악이 가장 웅장하고 감동적인 클라이맥스에 도달한 뒤 부드럽게 페이드아웃 ➡️ 확신에 찬 아이 목소리.
입력 프롬프트 + 출력 결과:
Animate this 2D illustration... A warm, mystical golden light gently emanates and glows from the open pages of the Bible, softly illuminating the boy's face...
➡️ 성경에서 나오는 은혜로운 빛을 받으며 행복하게 미소 짓는 소년 영상 출력.
파일명/링크: video_scene_04_enlightened_boy.mp4
